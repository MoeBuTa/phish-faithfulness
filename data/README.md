# data/

Nothing here is committed. Everything is regenerated from the commands in the
root README.

    raw/        PhreshPhish parquet shards, as downloaded
    interim/    C1 model outputs, generated C2/C3/C4 variants
    manifests/  frozen Dataset A/B/C row lists

Once a manifest is frozen, record its row count and SHA in
`docs/dataset_report.md` and do not regenerate it.
